# 界面外壳规格

覆盖窗口布局、竖向标签栏、分屏、会话启动器、会话编辑对话框、菜单、快捷键、关闭确认、显示设置和外观。终端内部的行为见 `terminal.md`，Filer 见 `filer.md`，Sender 见 `sender.md`。

视觉风格沿用现有版本：**竖向标签栏默认放在左侧**，参考 Warp 的布局思路；也可以在显示设置里改成每个分屏顶部各一条横向标签条（§2.5）。图标和素材必须使用许可允许的来源，不能使用 Warp 的素材。

## 1. 窗口布局

```
┌ 标题栏（透明，与内容融合）：侧栏开关 │ 命令面板 │ 右侧状态 ┐
├──────────┬────────────┬───────────────────┬──────────────┤
│ 竖向标签栏 │ Filer（可收起）│ 分屏区              │ Git 改动（可收起）│
│          │            ├───────────────────┴──────────────┤
│          │            │ Sender（可收起）                    │
├──────────┴────────────┴──────────────────────────────────┤
│ 状态栏                                                      │
└────────────────────────────────────────────────────────────┘
```

- **Filer 在标签栏与分屏区之间**（沿用旧版布局，见 `docs/design/reference/filer.png`）；Git 改动面板在分屏区右侧，两者可以同时打开（filer.md §10.1）。
- 面板（左侧标签栏、Filer、底部 Sender）各自可以显示或隐藏，快捷键为 ⌘⌥← / ⌘⌥→ / ⌘⌥↓；Git 改动面板由标题栏右侧的"改动"按钮开关（filer.md §10.1）。
- **窗口状态要能恢复**：下次打开时窗口大小与上次关闭时一致，关闭时是最大化的，打开时也最大化。新版还要恢复面板宽度和显隐状态。
- **命令面板**（新版新增）：标题栏中央放一个搜索框，可以搜索打开的标签、已保存的会话、菜单命令，以及当前目录下的文件。快捷键 ⌘⇧P（Windows / Linux 为 Ctrl+Shift+P），与 VS Code 的命令面板一致；不用 ⌘P，以免和打印冲突。可以重新绑定。

## 2. 竖向标签栏

### 2.1 顶部工具条（固定在顶部，标签再多也不会被滚走）
- **标签 / 会话切换**（左侧栏顶部紧凑分段栏，小圆角）：在「已打开的标签」与「已保存的会话管理（§4）」之间切换。标签段显示当前打开的标签数；切换到「会话」时若有后台未读完成，标签段显示未读圆点提示。
- **搜索框**（「标签」页）：按**本地路径**筛选标签。
  - 只匹配能确认的本地路径；SSH 和 SFTP 标签不拿连接名称冒充路径。
  - 不区分大小写，同时兼容 Windows 和 Unix 两种路径分隔符。
  - 只影响显示，不改变标签顺序、当前标签和分屏状态。
  - 按 Esc 清空搜索框。
  - 没有匹配结果时显示"没有匹配的路径"。
- **过滤按钮**（新版新增）：按会话类型（本地 / SSH / SFTP）和活动状态（运行中 / 有未读完成）筛选。
- **＋ 按钮**：直接打开 §5 的新建会话对话框。
- **会话管理 / 启动器**（§4）：点击侧栏顶部「会话」切换，或通过菜单「会话启动器」打开。连已保存会话、管理分组与 MCP 授权从这里进入。没有单独的快捷键。

### 2.2 标签行
每一行由以下部分组成：
- **左侧图标**：
  - 本地 shell 显示提示符图标，SSH 显示服务器图标，SFTP 显示文件夹图标；
  - 正在运行 AI CLI 时，换成该工具的标识（没有可用标识时用通用图标），底色取工具的品牌色。
- **主标题**：
  - 用户为标签设置了自定义名时显示自定义名；清空自定义名恢复默认。
  - 默认标题：本地 shell 显示**当前所在的目录**（左侧图标已经说明这是 shell，真正能把它和其他 shell 区分开的是目录）；其他类型显示会话名称（名称说明它连的是哪台主机）。
  - 过长时**保留末尾部分**（路径最有辨识度的是最后几段；已改名时从末尾截断）。
- **副标题**：
  - 未改名时：本地 shell 显示当前目录所在的 Git 分支，**不在仓库里就不显示**（不要把目录在下面再重复一遍）；其他类型不显示。
  - 已改名时保留上下文：SSH / SFTP 显示原会话名称；本地 shell 显示当前目录，在仓库里时连同分支一并显示（例如 `~/work · main`）。
- **悬停时在右侧显示**：
  - 快捷键提示：前 9 个标签显示 ⌘1–⌘9，之后的显示序号；
  - 关闭按钮。
- **鼠标悬停提示**：协议和地址、AI 工具名称、分支、活动状态（"命令运行中"、"命令已完成，点击查看"、"AI 运行中"、"AI 已完成"），或者连接状态或错误信息。
- **状态样式**：选中、连接中、已断开、命令运行中、有未读完成。未读完成的高亮会一直保留，直到用户切到这个标签。
- 每个会话有一个颜色。配置里设置了颜色就用它，否则由会话 id 或名称稳定地生成，同一个会话每次都是同一个颜色。

### 2.3 多个分屏时
- 标签按分屏分组，每组上方显示"分屏 1、分屏 2……"，点击切换到对应分屏。
- 只有一个分屏时不显示分组标题。

### 2.4 交互
- 点击（鼠标按下时）切换到该标签。
- **拖拽排序**：
  - 纵向移动超过 5 像素才开始拖拽，普通点击不会误触发排序。
  - 只在同一个分屏组内排序。
  - 插入位置按其他标签的实时中点计算，被拖动的标签本身不参与计算，避免列表因为自身移动而反复改变基准、越拖越偏。
  - 拖动时其他标签让出位置，并显示插入指示线。
  - 只有正常松开鼠标左键才确认排序。丢失松开事件或者被打断时，只恢复界面，不改变顺序。
  - 拖拽期间如果有触控板滚动，先结束拖拽。
  - 新的一次按下之前，先清理上一次拖拽残留的状态，残留状态不能阻塞后续操作。
- **新版新增**：标签可以拖到分屏区，放到某个分屏的中间就并入该分屏，放到边缘就在那一侧新建分屏；也可以拖到另一个窗口。
- **双击标签行**：重命名该标签（弹出轻量输入框，与分组重命名一致；留空保存恢复默认标题）。
- **双击标签栏空白处**：复制当前选中的标签（规则见 §3.3）。
- **右键标签行**，菜单包括：
  - 重命名…（弹出轻量输入框；留空保存恢复默认标题）；
  - 编辑已保存的会话（只有来自已保存会话的标签才显示）；
  - 重新连接（只有来自已保存会话且已断开的标签才显示）：用该会话的配置建立一条全新会话，替换原标签并留在原位置；不复用旧会话 id，也不在共享连接已断开时偷偷重连（ssh.md §6）；
  - 关闭；
  - 关闭其他、关闭左侧、关闭右侧、全部关闭。这几项**只在同一个分屏组内生效**，与 VS Code 编辑器组里"关闭右侧"的行为一致；没有可关闭的标签时禁用。
- 当前标签通过点击、快捷键或新打开等方式变化时，自动滚动到可见位置。
- 标签栏的宽度可以拖动调整，整栏可以收起。

### 2.5 顶部标签条（可选位置）

显示设置里的"标签栏位置"可以选**左侧**（默认）或**顶部**。切换后立即生效，重启后记住。

- 选顶部时左侧竖向栏整个不显示，也不能拖出来；Filer、右侧栏、Sender 的位置不变。
- **每个分屏顶部各一条标签条**，只显示本分屏的标签，与 VS Code 编辑器组的做法一致。不再需要"分屏 1、分屏 2"分组标题。
- 标签条从左到右排列本分屏的标签，末尾是 ＋ 按钮（打开 §5 的新建会话对话框）。不提供路径搜索框和过滤按钮，按路径找标签用命令面板。
- 每个标签的内容沿用 §2.2：左侧图标、主标题（规则相同，过长保留末尾）、会话颜色、状态标记、悬停时显示快捷键提示与关闭按钮、悬停提示。横向空间有限，**副标题（Git 分支）不单独占行**，只出现在悬停提示里。
- 标签等宽：可用宽度够时每个标签取最大宽度，不够时一起变窄到最小宽度，再不够就横向滚动；活动标签变化时滚动到可见位置。
- 选中样式与 §2.2 一致：活动分屏的活动标签最强调，其他分屏的活动标签弱一些。
- 交互沿用 §2.4，把纵向换成横向：点击切换、同一分屏内横向拖拽排序（横向移动超过 5 像素才开始）、右键标签行菜单相同（"关闭左侧 / 右侧"对应竖向的"上方 / 下方"）、双击标签条空白处复制当前标签、右键空白处打开会话启动器。
- 只有一个分屏且没有任何标签时不显示标签条，直接显示空状态页（§11）。
- "显示 / 隐藏标签栏"（⌘⌥←）在顶部模式下显示或隐藏所有分屏的标签条，状态重启后记住；标题栏左侧的侧栏开关按钮在顶部模式下隐藏。

## 3. 分屏

### 3.1 布局模型
- 布局是一棵树：叶子节点是分屏，内部节点把空间分给子节点，方向是左右（行）或上下（列）。
- 尺寸用占父节点的**比例**表示，同一个节点下的比例加起来等于 1，所以布局与像素无关，适应任何窗口大小。
- 树始终保持规范形式：只有一个子节点的拆分要消掉；与父节点同方向的子拆分要并入父节点。例如三个左右排列的分屏是一行三个，而不是一行里套一行。
- 分屏的顺序按阅读顺序：从左到右，从上到下。切到上一个、下一个分屏时循环。

### 3.2 操作
- **向右拆分 / 向下拆分**（⌘\ / ⌘⇧\）：在当前分屏旁边新建一个分屏，占用它原来一半的空间。如果当前分屏所在的拆分方向正好相同，新分屏就作为同级节点加入。
- 拖动分隔条调整大小。每个分屏至少保留一个最小尺寸；相邻的两个分屏都已经到最小值时，分隔条不再移动。
- 分屏里最后一个标签关闭后，这个分屏自动收起，它的空间按比例分给相邻的分屏。
- **在分屏之间移动标签时，会话不能重建**：终端的回滚、Filer 所在的目录和正在进行的传输都要保留，只是换了显示位置。

### 3.3 复制标签
- 复制标签，或者拆分时在新分屏里打开同一个会话：
  - SSH 会话**复用已经认证过的连接**，再开一个 shell 通道，不会再要一次验证码（见 `ssh.md` §6）；
  - 本地 shell 用同一个配置重新启动一个，**起始目录是原标签此刻所在的目录**（取 shell 前台进程的工作目录；OSC 7 上报的目录可能属于在这个 shell 里 ssh 登录的远端，只在查不到前台进程时才用，且必须是本机存在的目录）。
- 同一个会话不能同时显示在两个地方，所以拆分时总是打开一个新会话。

## 4. 会话管理（侧栏「会话」页）

左侧标签栏模式下点击顶部「会话」切入（菜单「会话启动器」也会展开左侧栏并切到这里；顶部标签条模式下仍以浮层弹出）：
- 顶部为**搜索已保存的会话**（按名称、主机、用户名匹配）与 **＋ 新建会话**（打开 §5 的 SSH / SFTP 表单）。
- 点击「本地 Shell」按默认配置打开；右侧「自定义启动」可调整 Shell 命令行、起始目录、编码和 Locale。「打开」仅使用本次配置，「设为默认」保存给之后新开的本地 Shell。
- **搜索已保存的会话**：按名称、主机、用户名匹配。
- 已保存的会话**按分组**显示。点击某个会话或按回车就连接它。每一行有一个「…」菜单（右键打开同一份），菜单项为：编辑、移到某个分组、删除；Direct 版另有"MCP 访问"子菜单（`mcp.md` §7.2）。对 AI 开放（MCP 访问级别不是"关闭"）的会话，行尾显示 MCP 标记。
- "已保存的会话"标题旁边的"…"菜单：新建分组、导入 OpenSSH 配置。
- 点击分组标题前的箭头展开或折叠会话。当前窗口记住折叠状态。搜索时显示折叠组里的匹配会话，清空搜索后恢复原折叠状态。
- 每个分组的"…"菜单：重命名、删除；Direct 版另有"MCP 访问 ▸ 整组设为…"（`mcp.md` §7.2）。删除分组时，组里的会话要怎么处理，在 `store-import.md` 里定。
- 右键已经打开的终端标签，也可以直接编辑它对应的已保存会话。

## 5. 会话编辑对话框

字段按会话类型显示：
- **通用**：名称、类型（新建时为 SSH / SFTP）、颜色、分组。
- **编辑已有本地会话**：Shell 命令行（见 `local-shell.md` §1）、起始目录。
- **SSH / SFTP**：主机、端口、用户名、认证方式（密码 / 私钥 / agent）、密码、私钥路径、私钥口令、跳板机（从已保存的 SSH 会话中选择）。Direct 版还有 ProxyCommand（与跳板机二选一）。
- **终端**（本地和 SSH）：编码（下拉选择）、Locale（可选，格式校验规则见 `local-shell.md` §4）。
- **MCP 访问**（仅 Direct 版）：关闭 / 只读 / 完全，新建默认关闭，见 `mcp.md` §7.2。
- 保存时校验跳板链：不能形成循环，不能超过 8 跳，引用的必须是 SSH 类型的会话（见 `ssh.md` §5）。

## 6. 菜单

macOS 使用系统原生菜单栏。结构如下（新版可以调整分组，但这些功能都要有）：

- **Kanso**：关于、设置…（⌘,）、检查更新…（仅 Direct 版）、退出。
- **会话**：
  - 会话启动器、新建会话…（⌘N）、新建本地 Shell；
  - 上一个 / 下一个会话、上一个 / 下一个分屏；
  - 关闭会话；
  - 文件传输：用 XMODEM 发送…、用 XMODEM-1K 发送…、用 XMODEM 接收…、取消传输；
  - 时间戳与行号（四种模式）；
  - 导出数据…、导入数据…、导入 OpenSSH 配置…
- **编辑**：
  - 复制、粘贴、全选；
  - 选中即复制（开关）；
  - 右键弹出菜单（开关，关闭即"复制或粘贴"模式，见 `terminal.md` §8.1）；
  - 清除缓冲区；
  - 命令建议（开关）、清除命令历史…；
  - 查找…、查找下一个。
- **视图**：Sender、Filer、标签栏的显示开关；向右拆分、向下拆分；外观（跟随系统 / 浅色 / 深色）；显示设置…；键盘与鼠标…
- **窗口**：系统标准菜单。
- **帮助**：教程、恢复默认设置…

Windows / Linux 版的菜单放在应用内的菜单栏里，并提供窗口控制按钮（最小化、最大化 / 还原、关闭）。

## 7. 快捷键

默认值如下。**除了 ⌘1–⌘9 之外，都可以在设置的"键盘与鼠标"页里重新绑定**：点击某个命令的按键，再按下新的组合；也可以清空，让这个命令不绑定任何键。"恢复默认设置"会恢复整张表。

| macOS | Windows / Linux | 命令 |
|---|---|---|
| ⌘N | Alt+N | 新建会话对话框 |
| ⌘T | Ctrl+Shift+T | 新标签打开本地 shell |
| ⌘W | Ctrl+Shift+W | 关闭当前会话（仍连接时需要确认） |
| ⌘F / ⌘G | Ctrl+Shift+F / Ctrl+Shift+G | 查找 / 查找下一个 |
| ⌘K | Alt+K | 清屏 |
| ⌘J | Ctrl+Shift+J | 在 Filer 中显示 shell 的工作目录 |
| ⌘[ / ⌘] | Alt+[ / Alt+] | 当前分屏的上一个 / 下一个标签 |
| ⌘\ / ⌘⇧\ | Ctrl+Shift+\ / Ctrl+Alt+\ | 向右 / 向下拆分 |
| ⌘⌥[ / ⌘⌥] | Ctrl+Alt+[ / Ctrl+Alt+] | 上一个 / 下一个分屏 |
| ⌘1–⌘9 | Alt+1–Alt+9 | 切到第 N 个标签 |
| ⌘⌥← / ⌘⌥→ / ⌘⌥↓ | Ctrl+Alt+← / → / ↓ | 显示或隐藏标签栏 / Filer / Sender |
| ⌘C / ⌘V | Ctrl+Shift+C / Ctrl+Shift+V | 终端内复制 / 粘贴 |
| ⌘A | Ctrl+Shift+A | 全选终端缓冲区 |
| ⌘⇧P | Ctrl+Shift+P | 命令面板（新版新增） |
| ⌘= / ⌘- / ⌘0 | Ctrl+= / Ctrl+- / Ctrl+0 | 放大 / 缩小终端文字、恢复默认字号（直接改"显示"设置里的终端字号，所有终端一起变，步长 1，范围同设置） |

- 复制、粘贴、全选也在这张表里，所以喜欢 Ctrl+Insert / Shift+Insert 或者普通 Ctrl+C / Ctrl+V 的用户可以改。普通 Ctrl+字母被设为复制键时的特殊规则，见 `terminal.md` §8.2。
- 用户把某个命令改绑到其他键之后，原来的系统默认按键（例如 macOS 上的 ⌘C、⌘V、⌘A）必须失效，不能新旧两组键同时生效。
- 普通的 Ctrl+字母和 Alt+字母，除非用户主动绑定，否则永远不拦截（见 `terminal.md` §9）。

## 8. 关闭与退出确认
### 7.1 键盘与鼠标设置页

设置窗口中这一页从上到下为：
- **鼠标**卡片：中键（粘贴 / 无动作）、右键（弹出菜单 / 复制或粘贴）两个下拉框，下方说明"程序开启鼠标上报时，按住 Shift 由终端处理点击"。
- **选择**卡片：选中即复制（勾选框）。
- 各组快捷键卡片，以及"恢复默认快捷键"按钮。这个按钮只恢复快捷键表，不动鼠标和选择设置；帮助菜单的"恢复默认设置…"两者都恢复。

鼠标与选择设置存放在设置表的 `mouse` 分区，两个平台格式相同，随数据导出导入：

```json
{ "v": 1, "middleClick": "paste", "rightClick": "menu", "copyOnSelect": false }
```

- `middleClick`：`"paste"` | `"none"`；`rightClick`：`"menu"` | `"copyOrPaste"`。未知取值、缺字段、类型不对都用默认值。
- `mouse` 分区不存在时，从旧字段迁移一次并写回，之后只读写 `mouse`：
  - 1.0.7 的 `display.copyOnSelect`（两个平台）；
  - Windows 旧版 `windows.panels` 的 `right_click_menu`（`false` → `"copyOrPaste"`）。


- 关闭一个**仍处于连接状态**的会话时需要确认；已经断开的直接关闭。
- 批量关闭（关闭其他、关闭左侧、关闭右侧、全部关闭）时，**只确认一次**，并列出仍在连接的会话。
- 退出应用时，如果还有连接中的会话，确认一次。
- 有文件传输正在进行时，确认提示里要说明关闭会中断传输。

## 9. 状态栏

- 显示当前会话的状态、连接错误信息、时钟。
- 时间戳栏开关：在 AI CLI 会话里只作用于当前会话（见 `terminal.md` §2）。
- Filer 开关。
- **Legacy SSH 标记**：当前会话有任何一跳使用了旧算法时显示；悬停时每台服务器占一行，列出它用的算法（见 `ssh.md` §2.2）。

## 10. 显示设置

- 界面字号与终端字号、各自的字体族。
  - 不内置任何字体。字体族留空就使用平台默认字体。
  - 终端字体只列出本机安装的**等宽字体**，界面字体列出全部字体；两者都允许手动输入任意名称，方便使用私有构建的 Nerd Font。
  - 装了 Nerd Font 时，终端字体缺少的图标字形自动回退到 Nerd Font。这样 Powerlevel10k、Starship 打印的图标不用额外设置就能显示。
- 光标形状和是否闪烁、回滚行数（见 `terminal.md` §15）。
- 标签栏位置：左侧 / 顶部（§2.5）。
- 外观：跟随系统 / 浅色 / 深色；浅色和深色各自对应的终端配色；最低对比度保护（见 `architecture.md` 主题一节）。
- 设置可打开数据目录下的 `themes/`。符合 [v1 文件格式](../design-tokens.md#安装用户终端配色) 的 JSON 自动出现在浅色和深色配色列表。切回设置时重新读取，选择即时应用到打开的终端，并按文件名持久化。
- 语言：macOS 跟随系统，通过系统设置里的"按 App 设置语言"切换；Windows / Linux 在设置里提供（见 `architecture.md` 多语言一节）。

## 12. 验收用例

- 本地 shell 标签的主标题会随 `cd` 更新；副标题在仓库里显示分支，离开仓库后消失。
- 拖拽排序：轻点不会触发；拖动途中用触控板滚动不会留下残留状态；中途丢失松开事件时顺序不变。
- 有三个分屏时，"关闭右侧"只关闭同一组里的标签。
- 标签在分屏之间移动后，终端回滚和正在进行的传输都还在。
- 复制一个需要验证码的 SSH 标签时，不会再要一次验证码。
- 把复制键改绑到其他组合后，⌘C 不再执行复制。
- 标签栏切到顶部后，每个分屏顶部各有一条只含本分屏标签的标签条，左侧竖栏消失；切回左侧后竖栏恢复，标签顺序和活动标签都不变。
- 关闭窗口时窗口是最大化的，重新打开后仍然是最大化。
- 界面在浅色、深色和伪本地化（文字拉长）三种情况下都不会出现截断或重叠。

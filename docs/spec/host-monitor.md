# 服务器监控规格

覆盖标题栏「监控」打开的右侧栏内容：当前已连接主机的资源概览。布局见 `ui-shell.md` §1。本功能不经过 MCP，也不看会话的 MCP 访问级别（`mcp.md`）。

## 1. 跟谁走

- 跟当前标签。已连接的 SSH 终端，以及这条 SSH 连接上的纯 SFTP 会话，显示采样结果。
- 本地 shell、尚未连上、已经断开、没有标签时，显示空状态，说明当前不是已连接的 SSH 会话。不沿用上一台主机的数字。
- 切到另一个标签后，下一次采样属于新标签；过时的结果不能画回去。

## 2. 怎么采

- 在该会话已经持有的 SSH 连接上另开一条 exec 通道，不请求 PTY，不往用户正在看的 shell 里打字。
- 一次采样只用这一条通道，读完或失败后立刻关掉。不把连接再留一份给监控自己：用户关掉这条连接上的最后一个标签时，连接照旧断开（`ssh.md` §6）。
- 命令是固定的只读探测，只认 Linux `/proc` 与 `df -Pk`。探测脚本里包含约 1 秒的间隔，用来计算这一拍的 CPU 占用。
- 面板可见时，上一拍结束后约 2 秒再采下一拍。收起右侧栏、改去看 Git 或智能体、或会话断开时停止。
- 单次输出最多保留 64 KiB，整次采样最多等 4 秒。超时或超限就关掉通道，并说明这次没采到。远端进程可能还在，与 `mcp.md` 里后台执行的说明相同。

## 3. 画什么

- 负载（1 / 5 / 15 分钟）、这一拍的 CPU 占用、内存与交换区（已用 / 总量）、各挂载点的已用空间、各网卡自开机以来的收发字节。
- 界面只画这些数字。网卡速率用相邻两拍的计数差除以间隔，第一拍只有累计值。
- `/proc` 不存在时说明这台主机不支持这种采样，不把命令输出伪装成数字。
- 命令失败、输出对不上、连接已断时，就地显示原因，面板不关掉。

## 4. 不做

- 不做进程列表，不做 Docker。
- 不在本地 shell 上跑同一套 `/proc` 探测。

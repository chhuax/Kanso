# 功能规格

本目录是新版 Kanso 的需求来源。每份规格只描述**要做到什么、边界情况、为什么这样做**。

编写规则：
- 不放代码片段、伪代码、类型或函数定义，也不画模块结构图。
- 不沿用旧实现的模块划分和命名，实现方式由新代码自行设计。
- 涉及协议或外部系统的结论，尽量注明一手出处（RFC 编号、OpenSSH 选项名、Apple 文档主题）。
- 标 **[MAS]** 的条目是 App Store 沙盒版的差异；标 **[待定]** 的是还没拍板的产品决策。

| 文件 | 范围 |
|---|---|
| `ssh.md` | SSH 连接、算法、主机密钥、认证、跳板、通道、SFTP 文件操作与传输、远端工作目录 |
| `encoding-transfer.md` | 编码转换、ZMODEM、XMODEM |
| `store-import.md` | 凭据、会话与分组的一致性、Sender 命令、命令历史、`.kanso` 导入导出、OpenSSH 配置导入、存储位置 |
| `local-shell.md` | 本地 shell 启动、login shell、环境变量、locale、zsh 提示符集成、本地工作目录查询 |
| `ui-shell.md` | 窗口布局、竖向标签栏、分屏、会话启动器、会话编辑对话框、菜单、快捷键、关闭确认、状态栏、显示设置 |
| `terminal.md` | 输出处理、时间戳/行号栏、清屏语义、命令分隔线、命令跟踪、AI CLI 识别、语义着色、剪贴板、按键、链接、搜索、工作目录上报、IME |

其余规格的清单和进度见 `docs/plan.md` §1。

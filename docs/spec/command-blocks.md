# 命令分块显示规格

新版新增功能（旧版没有），参考 Warp 的"块"观感，但**只是叠加在现有终端上的装饰**：不改终端网格内容、不插入行、不改变 shell 的输入方式，输入仍在提示符处。默认开启，**不提供开关或风格设置**（产品决定，2026-11-15）。

共用约定直接引用，不重复定义：

- 分隔线的画法、去重、像素对齐、重排、全屏程序不画：见《终端规格》§4。本规格在其基础上扩展。
- 命令开始、结束、退出码的来源（OSC 133 A/B/C/D 及无 OSC 133 时的推断）：见《终端规格》§5。
- 选区与复制：见《终端规格》§8。

## 1. 什么是一个块

- 一个块从某个提示符（OSC 133 A）开始，到下一个提示符之前结束；包含提示符行、命令行和这条命令的输出。
- **只对有 OSC 133 标记的提示符分块**（与分隔线同一规则）。没有标记的会话（通常是远程）不分块、不显示块装饰，现有分隔线规则不变。
- 命令文本取 B 到 C 之间的屏幕内容；输出取 C 到 D（或下一个 A）之间的行。还没执行命令就重新出现提示符（空回车、Ctrl+C）的，不算有命令的块：不显示状态、不提供复制命令/输出。
- 回滚被裁掉的部分不再属于任何块；块起点被裁掉后，该块只保留仍在屏幕/回滚里的部分，复制命令不可用。
- 清屏（《终端规格》§3）后，被清掉的块不再显示装饰。
- 全屏程序（备用屏幕）期间不显示任何块装饰；退出后恢复。

## 2. 块的装饰

- **不显示状态标签和耗时**（产品决定 2026-11-16：命令行右端的"✓ 耗时 / ✗ 退出码"标签观感突兀、位置奇怪，删除）。
- **不做单击选中整块高亮**（产品决定 2026-11-25：单击高亮整块缺少直接操作入口且容易误触，去掉整块选中底色）。
- **失败块的左侧色条**：退出码非 0 的块，在终端左侧内边距里画一条 2 像素宽的红色竖条，覆盖整个块的行范围；成功块不画。运行中的块画强调色细条。
- 时间戳栏开启时，色条画在时间戳栏与正文之间，不与时间戳重叠。
- 颜色取自当前配色，浅色、深色外观都要清晰可辨。

## 3. 复制

- **不显示悬停高亮和悬停复制按钮**（产品决定 2026-11-16：按钮太小、用途不直观，先去掉）。
- 右键菜单在块内时增加"复制命令""复制输出"两项，不另造菜单体系；没有命令的块不加。
- 复制的文本与普通选区复制规则一致（软换行合并、行尾空白去掉）；复制后在状态栏短暂提示"已复制"。

## 4. 跳转

- ⌘↑ / ⌘↓ 滚动到上一个 / 下一个块的提示符行，并让该行出现在视口顶部附近；没有更多块时不动。快捷键进入《界面外壳规格》§7 的快捷键表，可重新绑定。
- 跳转不改变普通文本选区和 shell 输入。

## 5. 性能

- 块边界随终端输出增量维护，不在每帧扫描整个回滚；装饰只为可见行绘制。
- 大量输出（例如 `yes | head -n 1000000`）期间帧率不应明显低于没有块装饰时。

## 6. 验收用例

- 本地 zsh 执行成功、失败（`false`、`exit 3` 的子 shell）、无输出、长输出命令：左侧色条正确；空回车和 Ctrl+C 不产生色条。
- 窗口变窄导致重排后色条位置正确。
- 进入 vim / top 后装饰消失，退出后恢复。
- SSH 远端没有 OSC 133 时无任何块装饰；远端自带 OSC 133 时正常分块。
- 右键菜单的复制命令、复制输出内容正确；块外右键不出现这两项。
- ⌘↑ / ⌘↓ 在块之间跳转；回滚裁掉早期块后跳转与复制不出错。
- 清屏后旧块装饰消失。
- 时间戳栏开 / 关两种情况下色条与时间戳不重叠。
- 单击选中、再次单击取消、单击另一块改选、块外 / 空提示符取消；双击 / 三击不触发块选中。
- 拖动、键盘输入、清屏、备用屏幕、回滚裁剪取消块选中；鼠标上报模式下点击照常传给程序。
- ⌘↑ / ⌘↓ 选中实际目标；无普通文本选区时 ⌘C 复制整块并提示，有选区时保持原有复制行为。
- 深浅主题与时间戳栏开 / 关时，只有选中块的行出现高亮，覆盖正文左右留白，文字背景、文本选区、光标和失败红条正常。

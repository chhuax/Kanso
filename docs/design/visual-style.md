# 视觉风格

界面风格沿用旧版 Kanso（用户自己的设计）。参考截图在 `docs/design/reference/`：

- `launcher.png`：点 ＋ 弹出的会话启动器；
- `session-editor.png`：新建会话对话框，背景里能看到整体窗口（标签栏、终端、状态栏）。

**只参考截图里的视觉设计，不参考旧仓库的任何代码。** 颜色以 `design/tokens.json` 为唯一来源；下面的色值是从截图取样得到的深色外观参考值，浅色外观按同样的层次关系推导。

## 1. 总体原则

- **实色、平直、低对比的层次**。不用系统的玻璃 / 毛玻璃材质，不用新版 macOS 控件默认的大圆角胶囊造型。
- 层次靠**背景明度的细微差别 + 1px 细边框**区分，不靠阴影（浮层可以有一层很淡的阴影）。
- 圆角小而统一：输入框、按钮、下拉 6pt；卡片、浮层、对话框 10–12pt。
- 强调色只用在：获得焦点的输入框边框、选中项、主按钮。其余一律中性灰。
- 字号克制：正文 13pt，标签与说明 11–12pt，标题 15pt 半粗。

## 2. 颜色层次（深色外观参考值）

| 用途 | 参考值 | 说明 |
|---|---|---|
| 窗口 / 终端区背景 | `#050505` 左右 | 接近纯黑 |
| 标签栏背景 | `#0B0B0B` 左右 | 比终端区略亮 |
| 选中的标签行 | `#212121` | 圆角块 |
| 浮层、对话框外壳 | `#151515`–`#1A1A1A` | 1px 边框 `#2A2A2A`–`#424242` |
| 对话框里的分区卡片 | `#151515` | 1px 边框 `#202020`，圆角 10 |
| 输入框、下拉框 | 底 `#0F0F0F`，边框 `#1E1E1E` | 获得焦点时边框变强调色 |
| 强调色 | `#15B8E0`（青色） | 焦点边框、选中、主按钮底色 |
| 选中的分段卡片 | 底 `#1E333B`，边框 `#1A8EAB` | 强调色的低明度版本 |
| 次要文字 | `#8A8A8A` 左右 | 标签、副标题、分区标题 |

## 3. 组件

### 3.1 输入框 / 下拉框
- 实色深底、1px 细边框、6pt 圆角、左右内边距 10pt，高度约 30pt。
- **标签在输入框上方**（11–12pt，次要文字色），不是左侧右对齐。
- 获得焦点：边框换成强调色（不用系统蓝色光晕）。
- 下拉框外观与输入框一致，右侧一个小的上下箭头。
- 占位文字用示例值（`example.com`、`user`、`Automatic`），不要写成说明句。

### 3.2 按钮
- 次要按钮：深灰底（约 `#2A2A2A`）+ 细边框，白字，6pt 圆角。
- 主按钮：强调色底，深色或白色文字（满足对比度），可以带一个小图标（例如"连接"带插头图标）。
- 纯图标按钮（铅笔、`…`、关闭 ×、齿轮）：无边框无底色，次要文字色，悬停时变亮。

### 3.3 对话框
- 外壳：实色深底、圆角 12、1px 边框，居中显示在窗口上（不是从标题栏滑下的系统 sheet 外观也可以，以视觉一致为准）。
- **头部**：左侧一个带底色的小图标徽章（圆角方块）+ 标题（15pt 半粗）；右侧关闭 ×；头部下方一条 1px 分隔线。
- **主体**：按主题分成若干**卡片**（例如"会话"、"SSH 连接"），每张卡片左上角是"图标 + 卡片标题"。
- 卡片内**两列网格**：成对的字段并排（名称 / 颜色、主机 / 端口、用户名 / 认证方式、编码 / Locale），单独的字段占满整行（密码、跳板机、分组）。
- **类型选择**用带图标的分段卡片（本地 / SSH / SFTP），选中的那个用强调色边框和低明度强调色底。
- **颜色**：两行色板，共 16 色，圆点约 22pt；选中的色点外加一圈白色描边。
- **底部**：右对齐的按钮组——取消、保存、**连接**（主按钮，保存后立即连接）。底部上方一条 1px 分隔线。

### 3.4 会话启动器
- **不用 `NSPopover`**（系统气泡带箭头和玻璃材质）：用无边框的实色浮动面板，圆角 12、1px 边框（`#424242` 一档）、淡阴影，出现在 ＋ 按钮下方，点击外部或按 Esc 关闭。
- 顶部是两个**列表式操作行**（不是按钮）：图标 + "本地 Shell"、"＋ 新建会话…"；右上角一个齿轮图标（打开设置）。
- 搜索框：§3.1 的输入框样式，左侧放大镜，获得焦点时强调色边框。
- "已保存的会话"小标题（次要文字色）+ 右侧 `…`。
- 会话行：左侧**小方块色点**（会话颜色），名称（主文字），下面一行 `user@host:port`（次要文字）；右侧铅笔与 `…` 图标。行与行之间没有分隔线，悬停时整行浅色高亮。
- 分组标题与"已保存的会话"小标题同样式。

### 3.5 窗口整体（来自 `session-editor.png` 背景）
- 标题栏与内容融合，接近纯黑。
- 标签栏顶部是路径筛选框（无明显边框的深色输入区）+ ＋；标签行选中时是圆角浅灰块，左侧图标放在小圆形底里，右侧显示 `⌘1`。
- 底部状态栏：左侧"文件浏览器""时间轴"、当前目录等带图标的文字项；右侧日期时间 `YYYY/MM/DD HH:MM`。文字次要色、12pt。

## 4. 浅色外观

截图只有深色。浅色外观保持相同的结构与层次：窗口最亮，卡片 / 浮层略暗一档或用细边框区分，输入框白底细边框；强调色用同一色相的深一些的版本，保证白底上的对比度。具体值在 `design/tokens.json` 里给出并通过 `cargo xtask check-tokens` 的对比度检查。

## 5. 实现对照（T10f）

组件库在 `apple/Kanso/App/UIKit/`：`StyledBoxView`（token 底座）、`KTextField` / `LabeledField`、`KPopUpField`、`KButton`、`KCard` / `KSegmentedCards`、`ColorPaletteView`、`DialogShellView` / `DialogSheetWindow`、`FloatingPanel`。新增界面一律用这些组件，不要重新引入 `NSPopover`、系统 bezel 按钮或 `NSPopUpButton`。与上文的有意出入：

- 色板选中描边用 `text.primary`（深色外观近白，浅色外观近黑），不是固定白色：浅色卡片上白色描边看不见。
- 色板没有单独的"无颜色"圆点：再次点击已选中的色点即取消选择（`nil` = 不指定颜色）。
- 对话框仍用 sheet 呈现（无边框透明窗口 + 圆角外壳），保留系统的模态性（主窗口不响应键鼠和菜单快捷键）；不是自建遮罩。
- 浮动面板的阴影是窗口阴影，随圆角轮廓绘制。
- 编辑对话框回车 = 保存（沿用旧行为），"连接"不抢默认键。

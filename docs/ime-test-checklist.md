# IME 人工验收清单

对应 `docs/spec/terminal.md` §16。自动化测试（`InputMethodTests`）用假输入法覆盖回调序列，但真实输入法的行为各有差异，
发布前必须人工逐条验证。

## 准备

1. 构建并运行 Debug 版：`cargo xtask apple-build` 后启动 `target/apple/DerivedData.noindex/Build/Products/Debug-Direct/Kanso.app`。
2. Debug 构建的输入先经过 `LoggingInputSink` 写入 `os_log`，再转发给 core（Release 不记录任何按键内容）。
   在终端里观察事件：`log stream --predicate 'subsystem == "com.chhuax.kanso" && category == "terminal-input"' --level debug`。
   - `key ...`：按键事件（含 `text`）；`textInput ...`：IME 上屏文字；`mouse ...`、`scroll ...`、`focus ...` 同名。
3. 要验证的输入法：**系统拼音、搜狗、微信输入法、豆包输入法**；另加一个日文输入法（系统自带"日语 - 假名"即可）。
4. 每个输入法把下面 7 个场景各走一遍，记录通过 / 失败与输入法版本。每一步之间可点击窗口再回到终端以重置状态。

通用判据：**每个字符恰好出现一次**（`textInput` 或带 text 的 `key` 各一条），组字过程中 `key` 不应出现回车 / 退格 / Esc。

## 场景 1：英文模式快速输入，第二个键不能丢

1. 切到输入法的**英文模式**（中英文切换键）。
2. 以最快速度连按 `a` `s` `d` `f`，重复 10 次。
- 预期：每次日志里依次出现 4 个 `key`（a、s、d、f），不丢、不重复、顺序正确。

## 场景 2：Shift 后的第一个全角标点不能丢

1. 切到**中文模式**。
2. 按住 Shift，立即按 `;`（输出 `：`）；松开后再试 `Shift+1`（`！`）、`Shift+/`（`？`）。每个标点测试时都是"刚按下 Shift 的第一个标点"。
- 预期：每次都有对应的 `textInput`（`：`、`！`、`？`），第一个标点不丢。
3. 再单击一次 Shift 切换中英文（有的输入法用它切换），确认切换仍然有效。

## 场景 3：空格确认拼音词组，不能重复上屏

1. 中文模式输入 `nihao`，看到组字下划线与候选框。
2. 按空格确认第一个候选。
- 预期：日志只出现一条 `textInput 你好`，**没有** `key` 空格；没有第二次 `你好`。
3. 用数字键 `2` 选第二个候选、用回车直接上屏拼音字母各试一次，结果同样只上屏一次。

## 场景 4：两次组字极短时间内先后完成

1. 中文模式，快速连续输入 `ni` 空格 `ni` 空格（越快越好，尽量一气呵成）。
2. 再试 `wo` 空格 `wo` 空格（两次内容相同的情况最容易被误去重）。
- 预期：两次的内容都上屏（`你你`、`我我`），一次不少。

## 场景 5：已上屏内容不重复发送

1. 输入 `zhongwen`，用空格上屏。
2. 立即点击窗口其他位置再点回终端；再输入下一个词。
- 预期：`中文` 的 `textInput` 恰好一条；切换焦点不会让它再次出现。
3. 组字到一半（不确认）点击别的窗口：组字被丢弃，日志里**没有**对应 `textInput`。

## 场景 6：组字期间回车、退格、Esc 归输入法

1. 输入 `nihao`（不确认）。
2. 按退格：组字缩短为 `niha`，日志里**没有** `key backspace`。
3. 按 Esc：组字取消，日志里**没有** `key escape`。
4. 再输入 `nihao`，按回车：拼音字母 `nihao` 以文本上屏（多数输入法如此），日志里**没有** `key enter`。
5. 无组字时再按一次回车、退格、Esc：这次日志里应出现对应的 `key`。

## 场景 7：候选框跟随光标位置

1. 在窗口中输入组字，观察候选框紧贴组字文本（光标所在单元格）下方。
2. 随着输入变长，候选框位置跟着组字起点，不跳到屏幕角落或窗口外。
3. 换到窗口不同位置的光标（窗口里 mock 内容会移动光标），移动窗口到副屏、调整窗口大小后再输入，候选框都应跟随。
4. 打开时间戳栏 / 行号栏与关闭时各测一次：候选框的水平位置应随栏宽正确偏移。
5. 组字文本很长（连续输入 40 个以上拼音字母）：文本整体左移贴住窗口右边缘，仍然完整可见。

## 日文输入法基本组字

1. 切到"日语 - 假名"，输入 `nihongo`：出现带下划线的 `にほんご`。
2. 空格转换：选中段（当前转换的文节）显示粗下划线；回车确认后 `textInput 日本語` 恰好一条。
3. 组字中按 Esc、退格：不发 `key`。
4. 组字中用 ← / → 在文节间移动：不应产生 `key arrowLeft/Right`（被输入法使用）。

## 其他快速检查

- 英文输入：`Ctrl+C`、`Ctrl+A` 总是 `key`（带 ctrl），不会变成编辑命令；`Option+a` 为带 text `å` 的 `key`；
  左右 Option 在日志里的 `mods` 分别为 `altLeft` / `altRight`；`⌘C` 没有任何日志。
- 鼠标：拖动选择时把鼠标移出窗口再松开，再次按下时日志里先出现补发的 `up`；窗口失去焦点（⌘Tab 切走）时进行中的拖动以 `up` 结束。
- 触控板滚动：慢速轻划不会每个像素都滚动，累积满一个单元格高度才出现一条 `scroll`；方向跟随系统"自然滚动"设置。
